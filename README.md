# Fases da Lua — Atividade prática com Antigravity

Projeto educacional para construir uma aplicação web interativa sobre as fases da Lua com apoio do Google Antigravity.

## Objetivo
Aprender desenvolvimento web, engenharia de prompts, requisitos de software e validação com critérios de aceite.

## Especificações
- [SPEC 01 — Visualização das fases](docs/SPEC-01.md): exibir e navegar pelas oito fases. **Homologação simulada: 5/5 aprovados** (exemplo didático, sem testes executados neste repositório).
- [SPEC 02 — Simulação do ciclo lunar](docs/SPEC-02.md): animar o ciclo sinódico de cerca de 29,5 dias, com controles.
- [SPEC 03 — Quiz interativo](docs/SPEC-03.md): cinco ou mais questões e apuração da pontuação.
- [Entrega e avaliação](docs/ENTREGA.md).

## Como executar
Abra `index.html` em um navegador moderno. O protótipo inicial implementa a navegação básica da SPEC 01; SPEC 02 e SPEC 03 ainda são atividades a desenvolver. Não confunda a homologação simulada do Trello com teste técnico do código deste repositório.

## Gestão
[Quadro Trello](https://trello.com/b/lyEsw5pj/atividade-pr%C3%A1tica-aplica%C3%A7%C3%A3o-fases-da-lua-antigravity) — cards de especificações e entrega.

## Uso do Antigravity
Leia a especificação de cada fase, solicite sua implementação à IA, revise o código, execute testes e reúna evidências verificáveis. Não aceite funcionalidades apenas por descrição textual da IA.
