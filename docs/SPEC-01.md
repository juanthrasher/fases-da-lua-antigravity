# SPEC 01 — Visualização Interativa das Fases da Lua

**Objetivo:** apresentar as oito fases com navegação, representação visual e texto.

## Requisitos
- RF01 — Exibir Lua Nova, Crescente Inicial, Quarto Crescente, Gibosa Crescente, Lua Cheia, Gibosa Minguante, Quarto Minguante e Minguante Final.
- RF02 — Mostrar representação visual de cada fase.
- RF03 — Permitir seleção por controles interativos.
- RF04 — Mostrar nome e descrição da fase selecionada.

## Critérios de aceite
- [x] Oito fases disponíveis.
- [x] Visual muda corretamente com a fase.
- [x] Nome e descrição correspondem à fase.
- [x] Navegação sem erros.
- [x] Interface organizada e responsiva.
