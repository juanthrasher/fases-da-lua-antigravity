# SPEC 02 — Simulação do Ciclo Lunar

**Objetivo:** demonstrar a sequência das fases em um ciclo médio de aproximadamente 29,5 dias.

## Requisitos
- RF05 — Animar a evolução das fases.
- RF06 — Oferecer controles Iniciar, Pausar e Reiniciar.
- RF07 — Exibir o dia aproximado no ciclo lunar.
- RF08 — Permitir ajuste da velocidade.

## Critérios de aceite
- [ ] Simulação percorre o ciclo completo na ordem correta.
- [ ] Iniciar executa a animação.
- [ ] Pausar mantém o estado.
- [ ] Reiniciar retorna ao início.
- [ ] Contador de dias acompanha a animação.
- [ ] Controle de velocidade altera o ritmo sem erros.
